What qualifies as a standout?

Each player-game can earn multiple categories, but only one standout game.

💯
550+ Score550+ points
⚽
Hat Trick3+ goals
🤝
Playmaker3+ assists
🔥
Offensive Engine2+ goals AND 2+ assists
⚓
Anchor5+ saves
🚌
Defensive Problem4+ saves AND (1+ G+A OR 3+ demos)
🛡️⚔️
Two-Way3+ saves AND 2+ G+A
💥
Elite Disruptor4+ demos AND 3+ G+A+S
👑
All-Around7+ G+A+S

Standout achievements are stat-based thresholds applied uniformly to recorded SHSU player-games. Each player can earn multiple categories in one game, but that game counts as one standout.
